# CH16 Checklist

## 用户体验

- [x] 没读过的文件不会被改掉。
- [x] 读完后用户自己改过的文件不会被覆盖。
- [x] Agent 刚写过的文件可以接着改，不必再读一次。
- [x] Ctrl+C 取消后，界面显示已取消，下一句还能发。
- [x] `-p` / 脚本不会停在“请确认”上。
- [x] 上下文太长时先看到重试，而不是直接失败。
- [x] 只读命令不再一个个干等。

## 风险控制

- [x] 危险命令、路径越界仍然优先于模式放行。
- [x] 无人值守遇到确认是否认拒绝，不是静默执行。
- [x] 未标注的 MCP 工具仍按有风险处理。
- [x] 取消 / 报错后不会留下半截工具调用。

## 产出效果

- [x] 编辑基于刚刚读到的内容，old_string 对不上就失败，不瞎改。
- [x] 长任务被取消后可以接着做，不用重开会话。
- [x] 压缩重试成功后任务能做完，而不是卡在中途。

## 自动验证

- [x] 先读后改 / 过期拒绝 / 写后可改 测试通过。
- [x] 配对修复与取消补齐测试通过。
- [x] `run_to_completion` 遇 ask 不挂起。
- [x] prompt-too-long 会 compact 并重试。
- [x] 白名单 Bash 进入并发批次。
- [x] 只读 MCP annotation 测试通过。
- [x] `ruff check simplecode tests` 通过。
- [x] `mypy simplecode` 通过（120 source files）。
- [x] `pytest -q` 全量 `528 passed, 1 skipped`。

## 明确不做

- [x] 不拆 UI 历史和模型投影两套存储。
- [x] 不做边生成边跑工具。
- [x] 不把 Bash 放进路径沙箱。
- [x] 不改 MCP 工具名。
